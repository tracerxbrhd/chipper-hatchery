# CHIPPER 0.2 — acceptance matrix / QA

**Продукт:** Chipper 0.2 «Living Hatchery»  
**Bot:** `@chipperhatcherybot` · **production-beta разрешён владельцем для релиза** после автоматических проверок.  
**Основа:** regression предыдущего `DOCS/ACCEPTANCE_0.1.md` + новые сценарии ниже.  
**Важно:** чеклист — требования, а не утверждение о пройденных испытаниях. Codex обязан создавать `DOCS/ACCEPTANCE_RESULT_0.2.md` с честными фактическими статусами.

## 0. Статусы

- `PASS — automated` с точной командой/тестом/SHA и логом;
- `PASS — live` с датой, приложением/платформой и проверенным действием;
- `PENDING — owner` — запланированная реальная проверка нескольких Telegram-аккаунтов;
- `BLOCKED` — доступ/SDK/окружение не дают исполнить;
- `FAIL` — действительно воспроизведённая ошибка, описать шаги.

Нельзя смешивать browser dev/mock, подписанный serverless вызов реального Telegram, живой HTTP и ручной приём владельца.
