# Chipper 0.5 — Personality & Visual Overhaul

0.5 makes the existing care/collection game visually distinct: expressive original oddball chicks, a layered day/night meadow, playful readable light/dark UI and floating Liquid Glass dock. All0.4 progress and economy survive.

Sources: owner's0.5 assignment, actual main3764261, saved GDD_0.3 §11 bilateral-exchange roadmap. Historical marketplace target is0.6; no standalone Issues were found. New implementation choices are described as0.5 decisions, not historical approval.

Core loop remains care, games, earning feathers and incubating birds. Exchanges require both friends' consent and preserve both birds. Collection comparison and personality previews make existing traits easier to appreciate. Small ambient comic events are local, positive and unrewarded. Twelve individual achievements derive only from authoritative server progress and have explicit idempotent reward claims, each +1 feather once per account; total lifetime new entitlement cap12. Client decorative interactions never unlock a paid milestone.

Non-goals: real payments, marketplace, public leaderboards, streak punishment, genetic rerolls, account reset, real-time multiplayer. Current release decision: defer the cosmetic store to0.6 continuation after an economy/transaction audit; no fictitious working checkout. Historical GDD0.3 schedules only Marketplace for0.6 and decor for "later"; the cosmetic-store target is not historical approval.
