# Визуальные доказательства локальной проверки

Скриншоты сняты Chromium 156 / Playwright 1.64.0 при реальном рендере React/SVG, 12.10.2026. Они **не являются** скриншотами настоящего Telegram и не подтверждают live auth. Баннер песочницы оставлен намеренно. Графика полностью программная и оригинальная.

- [home.png](home.png) — домашний экран, второй питомец выбран и переименован.
- [collection.png](collection.png) — два собственных экземпляра в локальной коллекции.
- [incubator.png](incubator.png) — пустой слот и недостаточный баланс, кнопка покупки заблокирована.
- [minigame.png](minigame.png) — настоящий игровой экран с зерном и счётом во время25с раунда.
- [mobile-dark-320.png](mobile-dark-320.png) — ширина320px, тёмная тема и reduced-motion; тест дополнительно проверяет data-theme=dark и отсутствие горизонтального scroll.
- [art-catalog.png](art-catalog.png), [art-catalog-dark.png](art-catalog-dark.png) — каталог12 вариантов ×3 стадии в светлой/тёмной теме, отрендеренный графическим субагентом.

Игровые скриншоты воспроизводятся `npm run test:ui`. Полный HTML report и failure traces сохраняются локально в ignored playwright-report/test-results и в CI artifact; исходники UI-тестов сохранены в репозитории. Управляемые часы применяются только в regression-тестах истечения попытки/фокуса; основной smoke действительно ждёт два25с раунда.
