# Chipper 0.1

Уютная Telegram Mini App для `@chipperhatcherybot`: один активный цыплёнок, забота без смерти и наказаний, коллекция из оригинальных обликов, инкубатор и игра «Собери зёрнышки». Интерфейс на русском. Редкость только косметическая; платежей, NFT и рекламы нет.

## Что работает

Первое бесплатное яйцо и интерактивное вылупление; имя и карточка питомца; кормление, игра и 45-минутный сон; три стадии взросления; 12 оригинальных SVG-обликов; переключение коллекции; глобальные награды за заботу и мини-игру; покупка яйца за 6 пёрышек и 3-часовая инкубация. Таймеры, валюту, случайность и владельца определяет сервер. Есть темы Telegram, безопасные отступы, настройки звука/движения/вибрации и повтор запросов после ошибки.

## Локальная разработка

Нужен Node.js 24. Точные версии зависимостей зафиксированы в package-lock.json.

```powershell
npm ci
Copy-Item .env.example .env.local
npm run dev
```

Откройте адрес из вывода Vite. Локальная песочница явно обозначена баннером и хранит синтетический профиль только в браузере. Она использует ту же чистую доменную логику, но не является Telegram-авторизацией, облачной SQLite или живым деплоем. `.env.local` игнорируется Git. Для запуска без песочницы удалите `VITE_DEV_MOCK=true`; вне Telegram появится ссылка на бота без игровых данных.

Production-сборка **всегда исключает** dev-adapter, даже при этой переменной в окружении. Произвольные `?mock`, `userId`, localStorage и `initDataUnsafe` не открывают production-профиль.

## Проверки

```powershell
npm run check
npx playwright install chromium
npm run test:ui
```

`check` включает TypeScript, синтаксис и импорты Serverless, ESLint, Vitest, production build, проверку исключения dev-кода и поиск шаблонов секретов в файлах и истории Git. Игровые тесты используют `node:sqlite`, управляемые часы и случайность, проверяют конкурентные запросы через реальные SQL-операторы адаптера. Playwright запускает отдельную явную песочницу и production preview, проверяет все основные экраны, полный настоящий 25-секундный раунд, offline retry и мобильные размеры.

На Windows ограничения sandbox могут давать `EPERM realpath` в Vite/Vitest. Выполните команды в обычном локальном терминале; этот сбой сам по себе не означает пройденные тесты.

## Сервер и выпуск

Живая версия0.1 опубликована12.10.2026: [открыть Chipper в Telegram](https://t.me/chipperhatcherybot?startapp), [production URL](https://app8924974998.tgcloud.ai/). Схема, Main Mini App, Menu Button «Играть» и webhook настроены; версия ожидает приёмки нескольких аккаунтов. Для Windows с системным VPN proxy смотрите раздел proxy в инструкции деплоя.

React + TypeScript + Vite; plain JavaScript в `tgcloud/`; официальный Telegram Serverless SDK и встроенная SQLite. Клиент вызывает `Telegram.WebApp.Serverless.call`. Платформа проверяет initData, endpoint дополнительно требует корректный `ctx.initData.user.id` и проверяет принадлежность каждого объекта.

Все эффекты одного игрока находятся в агрегате `chipper_players`. Единственное условное `UPDATE ... WHERE revision = expected RETURNING revision` сохраняет птиц, баланс, яйца, попытки и receipt вместе. При конфликте переход пересчитывается. Это избегает зависимости от неподтверждённых многозапросных транзакций SDK.

Точный путь выпуска: [DEPLOYMENT_0.1.md](DOCS/DEPLOYMENT_0.1.md). Нельзя подставлять выдуманный URL или токен в репозиторий. `push` публикует код и файлы; `migrate` отдельно применяет схему. Сначала проверяйте бот и существующее облачное содержимое.

## Приёмка и ограничения

[Результаты проверок](DOCS/ACCEPTANCE_RESULT_0.1.md), [реализация](DOCS/IMPLEMENTATION_0.1.md), [исходная матрица приёмки](DOCS/ACCEPTANCE_0.1.md), [API-контракт](DOCS/CONTRACT_0.1.md).

Живую авторизацию и A/B/C, A1/A2 проверяет владелец на своих аккаунтах. Локальные SQLite и браузерные тесты не заменяют эту приёмку. Постоянные receipts и история предотвращают повтор старой операции, но агрегат растёт и целиком переписывается: перед широким запуском потребуется безопасная компактация. Мини-игра имеет базовую защиту по попытке/времени/владельцу, не полноценный античит. Публичную политику приватности и процесс удаления данных нужно утвердить перед открытым запуском; массового reset endpoint нет.
